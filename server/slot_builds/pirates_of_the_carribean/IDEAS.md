## Dead Man's Map (bonus, from scatters)

Game flow:
1. The player receives a map showing a branching path through several islands.
2. At each island, the player chooses between two or three destinations.
3. Each destination triggers a different encounter:
   - Treasure Island: collect a guaranteed treasure.
   - Shipwreck: search for relics and potentially discover a special item.
   - Skull Island: face a dangerous encounter with a larger possible reward.
   - Port Royal: exchange collected relics for supplies or bonuses.
4. Some locations provide keys, maps, or artefacts that unlock alternative routes.
5. The player eventually reaches the final island, where collected items determine which parts of the legendary treasure can be claimed.
