# Sound library

The sounds the admin page's Sounds tab (`/maintenance#sounds`) offers for each game moment. Every file
here is public domain (CC0 1.0), except `star-trek/` (see its row): no attribution is required, but credit where it's due.
Files you upload on the page go in `<data dir>/sounds/uploads/`, not here.
